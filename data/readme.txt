data/ contains subdirectories with all input data required for RegionalBoxModel paper.

NADP: 
- Contains NADP AMNET files downloaded from their website - https://nadp.slh.wisc.edu/networks/atmospheric-mercury-network/

GCdata: 
- Contains subdirectories with output from each GEOS-Chem simulation (GC_output) and processed subsets of data (GC_processed). 
- Additionally, GMA emissions are included in this directory

pblh:
- Contains pblh data from existing literature (see discussion in main text) and MERRA2 reanalysis

boxmod_opt:
- Output from box model calibration exercise for generating solution space. 

These subdirectories and data can be accessed at Zenodo repository accompanying this paper ()
